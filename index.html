How to measure off the drawing

1. Set the scale. Click Set scale, then drag a line along any dimension you can read on the drawing — a 2000 mm opening width, say. Enter that real length in millimetres when prompted.

2. Measure openings. Click Measure and drag a box around an opening. Its width and height in millimetres are carried straight into the Add opening form.

3. Check against the drawing. Measured sizes are approximate. Always overtype them with the dimension printed on the drawing where one is shown.

Scale is per page — recalibrate when you move to a different sheet or a different drawing scale.

Measured dimensions are a drafting aid, not a substitute for a site survey. Verify all dimensions on site before fabrication.
